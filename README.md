# AX러닝랩 매출 대시보드

기업 AX 교육 서비스의 CSV 매출 데이터를 분석하는 React 대시보드입니다. 파일 파싱, 집계, 다운로드는 브라우저에서 처리합니다.

## 로컬 실행

Node.js 22.12 이상에서 실행합니다.

```bash
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run build
```

## CSV 통합 및 집계

- 여러 파일을 선택하거나 한꺼번에 끌어다 놓을 수 있습니다. 파일을 추가하면 앞서 올린 데이터가 유지됩니다. 첫 파일을 읽으면 초기 예시 데이터는 화면에서 내려갑니다.
- 쉼표, 탭, 세미콜론 구분과 UTF-8, CP949, BOM이 있는 UTF-16 파일을 지원합니다. 날짜, 서비스와 매출액이 필요하며, 고객사 또는 주문번호로 거래를 식별합니다. 매출액이 비어 있으면 유효한 수량과 단가를 곱합니다.
- 플랫폼 열을 우선 사용하고, 값이 없으면 알려진 파일명에서 추정합니다. 쿠팡, 11번가, 네이버 스마트스토어 주문 내역을 동시에 업로드할 수 있습니다. 모호한 파일은 **플랫폼·컬럼 확인**에서 직접 연결하세요. 연도가 마지막인 날짜의 월·일 순서도 파일별로 지정할 수 있습니다.
- 플랫폼과 주문번호가 같은 거래의 중복은 한 번만 집계합니다. 같은 고객사와 서비스의 주문에 명확한 취소·전액 환불 내역이 있으면 해당 상태로 대체합니다. 서로 충돌하는 내역은 확인 대상으로 표시합니다. 주문번호가 없으면 플랫폼·날짜·고객사·서비스·금액·상태가 같은 내역을 파일 간 중복으로 봅니다. 주문번호가 없는 정상 거래와 조정 내역은 자동 연결할 수 없습니다.
- 매출, 거래 건수, 평균과 차트는 정상 거래 기준입니다. 취소·환불 건과 환불 금액은 별도로 표시하며, 정상 매출에서 다시 차감하지 않습니다. 상태 열이 없는 파일에서는 음수가 아닌 유효한 금액을 정상 거래로 봅니다. 모호한 상태나 부분 환불은 확인 대상으로 남깁니다.
- 플랫폼과 기간 필터는 요약, 차트, 표, CSV 다운로드에 적용됩니다. 조회 시작일과 종료일을 모두 포함합니다. CSV에는 검색과 페이지에 관계없이 필터에 해당하는 정상·취소·환불 거래가 포함됩니다.
- **샘플 CSV** 또는 [public/samples](public/samples)에서 기존 샘플 3개와 통합 실습용 2개를 받을 수 있습니다. 통합 실습 파일 두 개를 함께 올리면 정상 매출 650,000원, 중복 제외 1건, 취소 1건, 환불 1건을 확인할 수 있습니다.

## Vercel

Vite 프로젝트로 가져오면 `vercel.json`에서 `npm run build`와 `dist` 출력 경로를 적용합니다. 별도의 환경 변수나 백엔드가 필요 없습니다.
