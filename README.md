# AX러닝랩 매출 대시보드

기업 AX 교육 서비스의 CSV 매출 데이터를 분석하는 React 대시보드입니다. 파일 파싱, 집계, 다운로드는 브라우저에서 처리합니다.

## 로컬 실행

Node.js 22.12 이상에서 실행합니다.

```bash
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run build
```

## CSV 사용

- 초기 화면에 가상의 표준 거래 50건이 표시됩니다. **샘플 CSV**에서 표준 파일과 구조가 다른 실습 파일 2개를 다운로드할 수 있습니다. 세 파일은 [public/samples](public/samples)에도 있습니다.
- 쉼표, 탭, 세미콜론 구분과 UTF-8, CP949, BOM이 있는 UTF-16 파일을 지원합니다.
- 날짜, 고객사, 서비스와 매출액이 필요합니다. 매출액이 비어 있으면 유효한 수량과 단가를 곱합니다.
- 열이 모호하면 **컬럼 설정**에서 직접 선택할 수 있습니다. 연도가 마지막인 날짜의 월·일 순서도 여기서 지정합니다.
- 문제가 있는 행은 행 번호와 이유를 표시하며 집계와 내보내기에서 제외합니다. **CSV 다운로드**는 검색 및 페이지와 관계없이 전체 유효 데이터를 저장합니다.

## Vercel

Vite 프로젝트로 가져오면 `vercel.json`에서 `npm run build`와 `dist` 출력 경로를 적용합니다. 별도의 환경 변수나 백엔드가 필요 없습니다.
